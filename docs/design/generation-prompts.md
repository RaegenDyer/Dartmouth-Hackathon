# Image generation prompts

Mode: built-in image generation. These are visual exploration prompts, not
implementation specifications or a finalized feature list. No existing artwork,
logos, or proprietary app screens are supplied as copying targets.

The reference catalog in `design-masters.md` informs the principles below. Each
direction selects a small compatible cluster; it does not try to combine all 100
references into one interface.

## Direction 01: Warm editorial

```text
Use case: ui-mockup
Asset type: high-fidelity app design exploration board, landscape 3:2.
Primary request: Design a polished desktop web app and matching mobile screen for a thoughtful text-based AI companion for adults getting settled in a new city. This is the actual app experience, not a marketing landing page. Product name and features are provisional. The design should make talking, reviewing one's own information, and choosing a small next step feel approachable and adult.
Design principles: human-scaled material warmth, disciplined editorial hierarchy, generous breathing room, clear and recognizable navigation. Use those broad principles originally explored through Eames/Aalto, Vignelli, Rams, and Kare references; do not reproduce any designer's signature work or brand.
Composition: a large desktop interface takes roughly three quarters of the board; a complete matching mobile interface sits beside it. A narrow bottom strip shows six larger custom raster icon samples. Keep the interface large, coherent, and readable, with only a few text elements. Small board label: "01 / Warm editorial".
Visual language: warm ivory canvas, deep forest-green text and primary actions, restrained terracotta accents, subtle paper grain. Elegant literary serif for the main greeting, crisp highly readable humanist sans serif for controls. Soft rectangular panels, fine rules, quiet spacing. The conversation is the dominant element; supporting modules can be replaced later.
Icon language: original rendered matte-ceramic and gently textured wood miniatures with dimensional silhouettes, subtle directional shadows, and tactile surfaces. Integrate them sparingly at sensible UI sizes. Include chat, home, bookmark, profile, settings, and optional microphone metaphors. These must visibly be raster illustrations, not flat SVG symbols, wire icons, emoji, or an off-the-shelf icon library.
Text, verbatim where used: "Companion", "Today", "Conversations", "Saved", "Settings", "Good evening, Alex.", "How was today?", "I'm still getting used to this city.", "We can take it one small step at a time.", "Your space", "Write a message...", "Send".
Content: show a short two-message conversation and an editable-looking supporting information panel. Include the same core content in the mobile screen. Use a clear, visible send button, labels beside navigation icons, and comfortable tap targets. All UI content is illustrative and mutable.
Avoid: purple AI gradients, dashboards full of metrics, loneliness scores, streaks, manipulative attachment language, clinical claims, robot mascots, romantic imagery, fake browser chrome, oversized decorative illustrations, illegible filler text, tiny controls, recognizable logos, watermarks. No voice-call or spoken-response controls; a small optional dictation input control is allowed.
Output intent: a realistic, distinctive app concept that could guide later HTML/CSS implementation. Do not show code or implementation annotations.
```

## Raster icon-family study

```text
Use case: stylized-concept
Asset type: original raster UI icon family, six isolated icons on a genuinely transparent background.
Primary request: A coherent family of six beautifully crafted, highly recognizable app icons, rendered as small physical matte-ceramic objects. Match a warm editorial companion app with ivory, deep forest green, and restrained terracotta materials.
Composition: a precise 3-column by 2-row grid with generous equal gutters. Each separate icon is centered in its own cell, at the same visual scale and camera angle, fully inside the canvas with no overlap. No labels, typography, tile backgrounds, frames, or contact-sheet decorations.
Subjects in reading order: a welcoming small house for Home; two overlapping conversation bubbles for Chat; a folded bookmark for Saved; a simple neutral human bust for Profile; a clear rounded gear for Settings; a recognizable microphone for optional dictation.
Style/medium: dimensional raster render, handcrafted matte ceramic with subtle real surface texture, softened but clear edges, consistent three-quarter view, soft upper-left studio light, minimal contact shadows contained close to each object. Readable silhouettes at small app sizes, professional and adult, not childish toys.
Color palette: warm ivory ceramic with forest-green faces and small terracotta details. Limit the palette and maintain strong silhouette definition on both light and dark UI surfaces.
Constraints: genuine alpha transparency around every object; preserve fine edges. No checkerboard baked into the image. No vector/flat SVG appearance, thin outline glyphs, emoji, generic icon-pack symbols, text, logos, gradients filling the background, watermark, or extra objects. This is an original generated raster study, not a production sprite layout with guessed crop coordinates.
```
